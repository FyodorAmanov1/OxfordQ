How the duet works · technical details & limits

A Bell state (|00⟩ + |11⟩)/√2 is freshly prepared. Four frozen, trained RY measurement angles select Alice's and Bob's local measurements. Each player's note uses only the pre-agreed score, timing and its own output. The referee checks a ⊕ b = x · y; it cannot correct, suppress or replace a voice's notes.

Frozen angles load with the take.

The local classical strategy shares randomness prepared independently of the cue sequence. Alice receives only x and her two-entry function; Bob receives only y and his. No communication of cues or outputs is allowed before producing notes.

A separate, previously trained 12-qubit / 84-parameter QCBM supplies four base motifs. Five-circuit mode samples it in this job. Four-circuit mode explicitly loads a recorded M3A draw. Both comparison methods use the identical melody, cues, sound design, levels and timing.

Ideal simulators, noisy simulators and recorded melodies are different sources. Simulator type is user-declared and exported with backend identity. Reconstructed playback is a random permutation of histogram counts, not a chronological measurement record. The 95% Hoeffding interval assumes independent shots and fixed equal allocation; it is never hardware-certified.

This is a centralized simulation of a noncommunicating task, not a physically separated Bell experiment. It is classically simulatable. The advantage is conditional on the communication restriction; better music and computational speedup are not established. Earlier classical models outperformed the QCBM on melody likelihood.
